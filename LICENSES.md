| What | Where it's used | Licence |
| --- | --- | --- |
| Original Rizalopoly illustrations (portraits, place emblems, capiz/banig/baybayin board motifs) | `src/assets/svg/`, generated from `tools/art/`, plus `src/board.js` | Made for this project |

| [GSAP](https://gsap.com) | Menu, splash and dialog animation | GSAP Standard License (free) |
| [Howler.js](https://howlerjs.com) | Sound playback | MIT |
| [Noto Sans Tagalog](https://fonts.google.com/noto/specimen/Noto+Sans+Tagalog), via Fontsource | Baybayin lettering | SIL Open Font License 1.1 |
| [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) and [Lato](https://fonts.google.com/specimen/Lato), via Fontsource | Fonts | SIL Open Font License 1.1 |
| [Vite](https://vitejs.dev) and `vite-plugin-singlefile` | Build tools | MIT |

The built-in sound effects and background music are synthesized in code and have no outside source.
