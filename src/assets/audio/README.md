# Custom sounds

Drop audio files here, named after the sound they replace, and the game plays them through Howler.js instead of the built-in synthesized sounds:

`dice`, `step`, `coin`, `pay`, `card`, `right`, `wrong`, `turn`, `exile`, `fanfare`, `build`, and `music` (loops in the background).

Formats: `.mp3`, `.ogg`, `.wav` or `.m4a`, for example `dice.mp3`. Use only sounds you have the rights to (CC0 packs from Kenney.nl or OpenGameArt work well), and list them in `LICENSES.md`.
